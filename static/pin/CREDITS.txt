PIN code → city / state shards (static/pin/<first 3 digits>.json)

Data: GeoNames postal codes for India — https://www.geonames.org
Download: https://download.geonames.org/export/zip/IN.zip
Licence: Creative Commons Attribution 4.0 (https://creativecommons.org/licenses/by/4.0/)
The data is provided "as is" without warranty of accuracy, timeliness or completeness.

Changes made: reduced to one city (the most common district listed for the PIN)
and one state per PIN; state names mapped to the official list (e.g. "Jammu & Kashmir"
→ "Jammu and Kashmir", "Pondicherry" → "Puducherry"); Leh and Kargil moved to Ladakh.
Only 6-digit PINs starting 1–8. Generated by src/lib/checkout/build-pin-shards.mjs.

The checkout only uses these to prefill City and State, which stay editable;
an unknown PIN never blocks an order.
